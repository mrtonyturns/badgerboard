## Decisions taken (owner asked for all bugs fixed; defaults chosen)

- **Past-due grace.** No lock on Stripe's `past_due` status. The account locks after the second failed attempt (`invoice.payment_failed`) or when the subscription becomes `unpaid`.
- **Proration.** Upgrades are invoiced immediately (`always_invoice`). If a self-serve card is declined, the change is refused with a 402 and the plan stays as it was. Immediate cancels bill any pending items, except for account deletion.
- **Trials.** A trial only upgrades within the same plan family, or from Scout.
- **Weekly refreshes.** AI profile refreshes run only within the owner's current monitoring slots.

## Known limitations

- **`*` in searches.** PostgREST turns `*` into `%` in `like` patterns and offers no escape, so a literal `*` in a search still acts as a wildcard (noted in `src/lib/pgFilter.js`).
- **`useDialog` stacking.** If a parent and a child dialog open in the very same render, the parent ends up on top of the stack.
- **Office-name matching.** In `enrich-prospects-background.js`, seeded office names ("Wisconsin State Assembly — District N") may not match contest labels when `district_name` is empty. This is a data-shape mismatch, not a crash; worth a look when tuning prospect enrichment.
